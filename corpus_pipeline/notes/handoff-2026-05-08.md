## Tools

13 Go binaries:
- `cmd/fetchcorpus` — registry-driven HTTP downloader (sha256 sidecars)
- `cmd/extractcorpus` — 13 format extractors (fixture, text, md_lingq_parallel, epub, gz, csv/tsv, leipzig, skvr, html, huggingface, riigikogu, erab, eeva; vrt + wiki stubbed)
- `cmd/aggregatecorpus` — 4-phase aggregator with `-scratch` flag
- `cmd/corpusverify` — hard/soft gates + fixture probes
- `cmd/corpuspromote` — smoke→pilot→full ladder
- `cmd/enrichcorpus` — omorfi (FI) + vabamorf or estnltk (ET) batch adapters
- `cmd/epubdeck` — per-book wordlist
- `cmd/scraperiigikogu` — Riigikogu polite scraper

3 Python batch scripts:
- `scripts/omorfi-batch.py` — FI direct-FST analyzer
- `scripts/vabamorf-batch.py` — ET direct-FST analyzer (preferred)
- `scripts/estnltk-batch.py` — ET higher-level wrapper (fallback)

Local Python venv at `corpus_pipeline/.venv/` with omorfi +
estnltk + vabamorf (bundled in estnltk) installed. omorfi data at
`corpus_pipeline/omorfi-data/*.hfst`.
