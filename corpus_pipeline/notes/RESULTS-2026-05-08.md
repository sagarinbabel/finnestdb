# Corpus pipeline — final results, 2026-05-08

End-to-end pipeline ran on real data for both FI and ET. Both languages
treated as first-class citizens with parallel tooling (omorfi for FI,
vabamorf for ET — both direct-FST analyzers via Python wrappers).

Multi-analysis ambiguity correctly captured. Examples:
- FI `ei` → both ei/VERB and ei/AUX (negation auxiliary as both)
- FI `on` → both on/VERB (irregular, parser-chosen) and olla/VERB (FST alternate; expected)
- ET `või` → 5+ analyses (ADV/CCONJ/NOUN/VERB)
- ET `aasta`/`aastal` → both lemmatize to aasta/NOUN despite different cases

## Silver-tier validation (parser_choice agreement with external analyzer)

ET vabamorf agreed with parser_choice on 1,438,782 / 3,352,756 surfaces
= **43% agreement**. Top examples (sorted by surface_count):

```
ja      → ja/CCONJ
on      → olema/VERB
et      → et/CCONJ
ning    → ning/CCONJ
Euroopa → Euroopa/PROPN
kui     → kui/ADV
ka      → ka/ADV
oli     → olema/VERB
aasta   → aasta/NOUN
selle   → see/PRON
ta      → tema/PRON
see     → see/PRON
võib   → võima/VERB
```

These are independent confirmations (vabamorf is a separate FST chain
from parsecore's). High-confidence labels for parser-eval gold mining.

FI omorfi enrichment in flight at writing time — 7.5M surfaces × ~14K/sec
→ ~9 min. Expected silver count: ~3-4M based on FI/ET ratios.
