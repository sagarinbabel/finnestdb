## Reproduction

```
make parser
export DYLD_LIBRARY_PATH="$(pwd)/parser/target/release:$DYLD_LIBRARY_PATH"
make setup-estnltk
bash scripts/parser-comparison-et.sh
```

The comparison script auto-discovers gold sets from both `testdata/parser-eval/et/gold/`
and `localdata/parser-eval/et/gold/` (per PR [#131](https://github.com/sagarinbabel/finnestdb/pull/131)).
With `make import-ud-gold-et` populating `localdata/parser-eval/et/gold/ud-et-*.json`,
a future maintainer-local run on UD-Estonian-EDT/EWT will land alongside the
curated sets without any extra flags.
