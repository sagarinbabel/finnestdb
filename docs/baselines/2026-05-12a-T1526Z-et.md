- `naeris` (now naeris/NOUN — should be naerma/VERB; "laughed" vs "turnip" ambiguity)

**et-manual regression** — `peatus` ("stopped"):

- 2026-05-07k: `analyzer:rust lemma=peatus pos=NOUN` → `resolution:dict lemma=peatuma pos=VERB` ✓
- 2026-05-12a: `analyzer:rust lemma=peatus pos=NOUN` → `resolution:dict lemma=peatu pos=ADJ` ✗

The verb `peatuma` ("to stop") is now losing to the adjective `peatu` at dict-resolution time. Reproduces with both stale and fresh ET FST tables → root cause is dict-side, likely PR #187's source-priority-first ranking change pushing an Ekilex `peatu/ADJ` row above the kaikki `peatuma/VERB` row. Filed as a follow-up.
