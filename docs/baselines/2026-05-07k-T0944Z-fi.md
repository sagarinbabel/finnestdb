> **Eval-semantics change in PR #130 — key to reading these numbers.**
> `Match.Full` now requires the parser's FEATS to match the gold's
> per-attribute FEATS when gold supplies a FEATS string. Curated gold sets
> (`fi-core`, `fi-grammar`, `fi-manual-v1`, `fi-manual-v2`) don't carry FEATS
> in their annotations, so `Match.Full` on curated sets degrades to the
> pre-FEATS semantics (lemma & POS & grammar_label) — Full% on curated sets
> is therefore unchanged from 2026-05-07j. UD test sets carry full UD FEATS
> in gold, so Full% on UD now reflects stricter matching: a token whose
> Number/Tense/Mood/Person diverges from gold (which the case-only Grammar
> metric can't see) no longer counts as Full-correct.
>
> **FST runtime state at measurement.** PR #128 made the FST runtime disk-load
> tables from `localdata/lemmatizer-fi-et/tables/`. On this measurement
> machine that directory is empty (only `testdata/lemmatizer/` holds the
> 12-form smoke fixtures, used by tests not the production lookup). The
> runtime treats the missing tables as `ErrNoTables` → "FST disabled, fall
> through to dict + case-suffix path". So this baseline measures the
> dict + case-suffix stopgap path with **FST off**. To reproduce the
> production-table state, run `make gen-lemmatizer-tables-fi VFST_PATH=…`
> against an upstream Voikko `mor.vfst`. (Visible in stderr at startup:
> `store: lemmatizer init failed (FST analyzers disabled): lemmatizer: no
> tables found under localdata/lemmatizer-fi-et/tables`.)

## Reproduction

See [`../PARSER_EVAL_METHODOLOGY.md`](../PARSER_EVAL_METHODOLOGY.md) for the full
methodology. Quick path:

```
make parser
export DYLD_LIBRARY_PATH="$(pwd)/parser/target/release:$DYLD_LIBRARY_PATH"
export FINNESTDB_OMORFI_CMD="$(pwd)/.venv-omorfi/bin/python $(pwd)/scripts/omorfi_adapter_example.py"
export FINNESTDB_OMORFI_TIMEOUT=60s
make setup-omorfi
bash scripts/parser-comparison.sh
```

UD JSON reports (`docs/baselines/2026-05-07k-T0944Z-ud-fi-*-test.json.gz`) are
summary-stripped — `cases[]` per-case detail is omitted to keep file sizes
proportional to the existing curated baselines (~250 KB instead of ~35 MB).
Re-running locally produces the full `cases[]` array.
