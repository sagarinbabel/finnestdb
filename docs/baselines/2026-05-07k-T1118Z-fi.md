**Reading**

- **Grammar: massive lift everywhere.** kaikki tags carry `Case=Ill|Number=Sing` (and similar) for nearly every form; the parser now projects these via `kaikkiTagsToFeats` at import time, and the case-label projection lands `Case=` matching gold's `grammar_label`. Result: grammar accuracy on `fi-grammar` (curated) jumped 59.5 → **98.6%** (+39.1pp), now within 1.4pp of omorfi's 100%. UD grammar held in the 78–84% band across all 4 treebanks.
- **Lemma / POS: zero movement.** As designed — the data-thread migration doesn't change which lemma/POS gets resolved; it just attaches FEATS to the resolved candidate.
- **Full: dropped vs. j by 13–31pp** because `Match.Full` is now FEATS-strict (PR [#130](https://github.com/sagarinbabel/finnestdb/pull/130)) — every gold-supplied FEATS attribute must match. The parser produces FEATS but disagreements on Number/Tense/Mood/Person at multi-attribute tokens drag Full% down. The remaining gap to omorfi's Full% on curated sets reflects the per-attribute FEATS disambiguation that omorfi's HFST-driven analysis does and the dict-only path doesn't.

## Reproduction

```
# Bootstrap one-time
make reduce-ekilex                            # raw → definitions/forms shards (~2 min)
make import-ekilex-details-et                 # ~30 sec

curl -sL -o localdata/kaikki/kaikki.org-dictionary-Finnish.jsonl.gz \
  https://kaikki.org/dictionary/Finnish/kaikki.org-dictionary-Finnish.jsonl.gz   # ~30 sec on good connection
go run ./cmd/importdict -lang fi -db finnestdb.db -backfill-feats \
  -file localdata/kaikki/kaikki.org-dictionary-Finnish.jsonl.gz \
  -source-key kaikki -source-name "kaikki.org" \
  -source-license "Wiktionary-derived; verify per source terms" \
  -source-attribution "kaikki.org dictionary data derived from Wiktionary"  # ~2 min

# Run eval
make parser
export DYLD_LIBRARY_PATH="$(pwd)/parser/target/release:$DYLD_LIBRARY_PATH"
export FINNESTDB_OMORFI_CMD="$(pwd)/.venv-omorfi/bin/python $(pwd)/scripts/omorfi_adapter_example.py"
export FINNESTDB_OMORFI_TIMEOUT=60s
bash scripts/parser-comparison.sh
```

UD JSON reports are summary-stripped (`cases[]` dropped to keep file sizes proportional to curated baselines, ~5 KB instead of ~30 MB).
