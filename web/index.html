    How FinEstDB works

    Most language apps make you study vocabulary in isolation. FinEstDB starts from the text you actually want to read, and builds your vocabulary outward from there.

    1

    Paste a text

    Drop in a paragraph, an article, or a chapter in Finnish or Estonian.

    2

    Parse the words

    We split the text into unique lemmas, show dictionary details, and let you triage rows as known or ignored.

    3

    Save a deck

    Turn the parsed vocabulary into review cards tied back to the source text you pasted.

    4

    Track progress over time

    Your known-word and due-review counts update as you review and mark cards known.

        Set up AnkiConnect

        Finnest imports cards from your local Anki collection via an Anki add-on called AnkiConnect. There's a one-time setup:

        1. Install Anki desktop. Download from apps.ankiweb.net if you don't already have it. The mobile and web versions can't expose your collection over HTTP.
        2. Install AnkiConnect.
          1. In Anki, open Tools → Add-ons (or press Ctrl+Shift+A).
          2. Click the Get Add-ons… button.
          3. Paste the code 2055492159 (or visit the AnkiConnect page) and click OK.
          4. Double-click the AnkiConnect entry in the add-ons list to open its config.
          5. Add "https://finne.st" to the webCorsOriginList section. It should look something like: 
            {
    "apiKey": null,
    "apiLogPath": null,
    "ignoreOriginList": [],
    "webBindAddress": "127.0.0.1",
    "webBindPort": 8765,
    "webCorsOriginList": [
        "http://localhost",
        "https://finne.st"
    ]
}
          6. Click OK, then restart Anki.
        3. Keep Anki running. AnkiConnect only answers while the Anki desktop app is open. Leave it open, then click Connect to Anki.
