# Claude Design pulls

Files fetched from the Claude Design project "finnest"
(https://claude.ai/design/p/019dd5cc-0b20-7338-90ab-a72534941d07) via DesignSync.

- `finnest-prototype.html` - "Aalto edition" interactive prototype (pulled
  2026-07-04). Its <style> header declares the design system: Paimio light /
  Sanatorium dark palettes (oklch), Newsreader + Inter Tight + IBM Plex Mono,
  12/18/28/999 radii, birch-grain motifs, restrained/bolder variants. The
  companion JSX views (aalto-landing.jsx, components.jsx, v2-*.jsx, …) remain
  in the Claude Design project and can be fetched the same way.

Owner note: the prototype brands as lowercase "finnest."; product decision is
**FinnEst** (grill Q53) - capitalization is corrected when the theme is
implemented in the app.
