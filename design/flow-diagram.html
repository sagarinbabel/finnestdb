User flow - consumer alpha

Four diagrams covering the full consumer alpha. The macro flow shows every path through the product; the leverage flow details the comprehension-projection → word-list → study-deck loop; the correction flow shows the cross-cutting "Wrong?" round-trip including signed-in user submissions. Toggle INK / PAPER above.

01 / Macro flow Anonymous → auth → main loop

Anonymous parse drops the user into a results table with a sign-up ribbon. After auth, the dashboard is the hub; the parse → results → save → deck → review inner loop carries most of the session time. The leverage page feeds back into the deck loop via study-deck creation. Cold-start branches off the dashboard for brand-new accounts.

02 / Correction flow Cross-cutting · ✎ Wrong?

Triggerable from any results row, deck-detail row, or review card. Two submission paths: flag-only (low effort) and propose-answer (expert). Signed-in users get a round-trip: submit → admin triage → accept/reject → notification → "My submissions" history.

03 / Leverage → Study deck Comprehension projection · word list · review loop

The comprehension projection ("learn 20 words → 81%") is only useful if the user can see which 20 words, review them as a focused deck, and watch coverage climb as they learn. This is the full end-to-end flow - the core motivation loop.

04 / Leverage page (alternate entry) Cross-deck leverage · filter by deck

The leverage page is the other entry into the study-deck flow. User picks a deck scope, sees aggregate comprehension, and creates a study deck from the top N words - same SaveAsModal endpoint as deck-detail.
