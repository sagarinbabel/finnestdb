01 / Macro flow Anonymous → auth → main loop

Anonymous parse drops the user into a results table with a sign-up ribbon. After auth, the dashboard is the hub; the parse → results → save → deck → review inner loop carries most of the session time. Cold-start branches off the dashboard for brand-new accounts.

02 / Correction flow Cross-cutting · ✎ Wrong?

Triggerable from any results row, deck-detail row, or review card. The new flag-only path captures users who notice a wrong parse but can't articulate the fix — signal we lose today. 

flowchart LR

    F["parse_feedback row
flag_only=true"]
    FX["parse_feedback row
+ proposed_lemma · pos
+ optional grammar · notes"]
    T["Submitted ✓ toast"]
    Q["Admin triage
/admin/feedback"]

    A -->|"✎ Wrong?
(hover · focus)"| M
    M -->|"◉ I don't know
the right answer"| F

    F --> T
    FX --> T
    T -->|"return to source row"| A
    F -.->|"flag-only filter"| Q
